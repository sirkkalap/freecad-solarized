# Repository Guidelines

FreeCAD appearance addon. Read README.md for installation and scope.
Keep preference changes reversible; preserve the first baseline on repeated
apply. Do not edit CAD documents or geometry. Imports must not apply colors.
Qt timers and styles belong on the FreeCAD GUI thread. Use four-space Python
indentation. Do not run tests unless requested. Do not install or publish
without user authorization. No automated test suite is currently configured.
